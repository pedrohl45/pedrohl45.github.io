## 🖤 Sobre o projeto

Site estático, em português e inglês, escrito do zero com **HTML, CSS e JavaScript puros** (sem framework e sem build). Paleta café com tema claro e escuro (segue o sistema e tem botão de sol/lua), layout responsivo e animações leves de entrada ao rolar a página. A versão em inglês fica em [`?lang=en`](https://pedrohl45.github.io/?lang=en).

## 🚀 Rodando localmente

Não precisa instalar nada. Clone e abra o `index.html` no navegador, ou, se preferir um servidor local:

```bash
git clone https://github.com/pedrohl45/pedrohl45.github.io.git
cd pedrohl45.github.io
python3 -m http.server 8000
# acesse http://localhost:8000
```

## 🌍 Publicação

O repositório se chama `pedrohl45.github.io`, então o GitHub Pages publica o branch `main` automaticamente em **https://pedrohl45.github.io**.
