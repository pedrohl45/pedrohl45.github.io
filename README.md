## 🖤 Sobre o projeto

Site estático, em português, escrito do zero com **HTML, CSS e JavaScript puros** (sem framework e sem build). Tema escuro, layout responsivo e animações leves de entrada ao rolar a página.

## 🧭 Seções do site

| Seção | Conteúdo |
|:---|:---|
| **Início** | Apresentação, botão para os projetos e links de GitHub e LinkedIn |
| **Sobre mim** | Formação, foco em backend e Linux, e o que estou buscando (estágio ou vaga júnior) |
| **Arsenal técnico** | Linguagens, backend, banco de dados, sistema e ferramentas |
| **Projetos** | Automação Fatec, API FATEC, TayamaBot, YamadaBot, Arch Linux e scripts |
| **Formação** | DSM na Fatec São José dos Campos e Aprendizagem por Projetos Integrados (API) |
| **Contato** | E-mail, LinkedIn e GitHub |

## 🗂️ Estrutura

```
pedrohl45.github.io/
 ┣ index.html   # marcação e conteúdo de todas as seções
 ┣ style.css    # tema escuro, variáveis de cor e responsividade
 ┗ script.js    # menu mobile, destaque da seção ativa e animações de entrada
```

## 🛠️ Tecnologias

- **HTML5, CSS3 e JavaScript** puros
- **[Lucide](https://lucide.dev)** para ícones
- **[Devicon](https://devicon.dev)** para os ícones de tecnologias
- **Google Fonts**: Inter e JetBrains Mono
- **GitHub Pages** para publicação

## 🚀 Rodando localmente

Não precisa instalar nada. Clone e abra o `index.html` no navegador, ou, se preferir um servidor local:

```bash
git clone https://github.com/pedrohl45/pedrohl45.github.io.git
cd pedrohl45.github.io
python3 -m http.server 8000
# acesse http://localhost:8000
```

## 🌍 Publicação

O repositório se chama `pedrohl45.github.io`, então o GitHub Pages publica o branch `main` automaticamente em **https://pedrohl45.github.io**.
